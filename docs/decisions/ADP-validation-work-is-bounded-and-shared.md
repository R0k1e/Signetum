# Validation work is bounded and shared

Status: Accepted
Review date: 2026-10-29
Supersedes: None
Superseded by: None

## Context

The owner approved the reviewed Perdura workflow migration and concrete test
consolidation plan. The corpus grew through ordinary-text multipliers, duplicate
frontend matrices, repeated repository setup and independent execution entrypoints.
The protocol and its tooling are Signetum's product, so wholesale removal of
development-tool tests would remove product evidence.

## Decision

Core tests own pure combinations. Real public traversals retain repository,
authorization, locking, atomicity, process and receipt boundaries. Generated and
installed runtimes retain independent representative executions rather than a
mechanical duplicate of every shared matrix. Classify existing evidence before
adding tests and preserve the distinct behavior each removed test protected.

Explicit diagnostic test targets use the repository's declared test command,
resource allocator, supervisor and first-failure policy without readiness
receipts. Local diagnostics and CI use this owner. Nested allocations cannot
multiply the enclosing capacity. Without a selection provider, changed and ready
continue to run the complete member-safe gate; final always runs its complete gate.

Admission and conflict continuation prepare and run batch static checks only.
Final owns complete integration validation. Static failure retains the pending
merge and resolved index. Exact member evidence and explicit delivery remain.

Use one locked static-tool version and avoid duplicate gate execution. Reuse
successful immutable preparation only; mutable repositories, journals and
consumers retain independent ownership. Record phase cost and allocation in
existing diagnostic logs. Measurements are observations, not timing/count gates
or a second committed inventory. Current documentation describes current behavior;
this record and source history preserve the reasons.

## Approval and enforcement

The owner's agreement to the reviewed plan authorizes these changes. The
consolidated record binds outcomes, exclusions and acceptance. Existing product
contracts, selected public regressions, generated/installed execution and clean
readiness verify the result. Stop before real integration, delivery, publication
or any Perdura modification.
