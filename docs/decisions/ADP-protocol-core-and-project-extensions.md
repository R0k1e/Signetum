# One protocol core with project-owned extensions

Status: Accepted
Review date: 2026-10-30
Supersedes: ADP-development-feedback-is-bounded-and-derived.md, ADP-reliable-agentic-protocol.md
Partially supersedes: ADP-development-feedback-is-bounded-and-derived.md, ADP-reliable-agentic-protocol.md
Superseded by: None

The owner approves a smaller Signetum that helps people decide and supports
isolated parallel development through reliable integration and delivery.
Signetum owns approval, significant history, source-bound qualification and exact
publication. Projects extend declared preparation, checks and selection; they do
not maintain another readiness, receipt, journal or delivery writer.

Keep the versioned selection interface, not the built-in Python dependency
algorithm. Comparison exposed missing module-string, python -m and pytest_plugins
edges, and Perdura's namespaces and shard exclusions require project knowledge.
Self-use runs the full member gate. A provider is responsible for dependency
semantics; core checks identity, targets and conservative fallback and never
narrows final. Reopen bundled language analysis only for demonstrated shared
consumer demand with its own ownership and behavioral evidence.

Keep common instructions in the standard Skill. Local adoption material names
bindings and how to load that Skill. Agent-authored review highlights consequential
choices and alternatives; routine work follows accepted autonomy. Parallel guidance
names scopes, dependencies, shared interfaces and integration ownership, without
adding a scheduling service or another persisted planning model.

Internal fixtures and their renderer belong to tests. Remove future ADR numbering
mutation and unused configuration helpers; retain original accepted history and
necessary identity reads. Journal storage remains locked, atomic and approval-bound;
the existing protocol CLI owns arguments and derived views remain read-only.

Do not copy Perdura's whole runner into the engine. Its application checks and
preparation stay local behind compatible bindings. First failures remain failures;
a retry supplies diagnosis. Complete a real downstream adoption before claiming
Perdura operates on this protocol.
