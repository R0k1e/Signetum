# One maintained source per responsibility

Status: Accepted
Review date: 2026-10-30
Supersedes: None
Superseded by: None

The owner requests a minimal useful repository and consistent Signetum naming.
Use `.agents/signetum` for maintained project bindings and runtime outputs;
original historical approvals and journals retain their recorded bytes.

Maintain the engine once. Portable modules remain deterministic derived artifacts,
materialized for rendering and validation rather than committed source copies.
Fresh checkouts must work through the ordinary render/test path. Keep independent
portable and installed behavioral evidence and refusal of altered runtime bytes.

Keep current documentation at its responsibility owner and merge overlapping user
explanations. Retain consequential history and active cross-change authorities;
file count alone cannot justify destroying their basis or removing supported
features. Remove unused teaching/configuration assets and obsolete schemas only
after tracing consumers. Exact evidence retirements preserve original answers.

Test modifications are user-visible work: disclose affected files, reason and
replacement evidence, and explicitly identify any reduced coverage or relaxed
checks. Keep this explanation in the existing review rather than another report.
