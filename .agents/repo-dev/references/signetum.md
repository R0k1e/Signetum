# Foundation policy

Generic mechanisms stay in `signetum`; repository facts stay in
the specialization manifest, change packages, architecture, and adapters.
Validation is check-only. Publishing and delivery require explicit authority.
Unsupported schema and profile identities fail without fallback interpretation.

Present the approved behavior and acceptance evidence before implementation.
Record every delivery-relevant discovery through the Signetum deviation API;
do not keep it only in chat or edit its JSON Lines state directly. Safe
implementation clarification may continue, but freeze an affected unauthorized
decision while independent work proceeds. Before final validation, reconcile
every retained deviation into the applicable durable authority or an explicit
terminal disposition. After final, present the generated commitment-to-delivery
review before requesting explicit delivery.
