Read the setup guide
What gets installed?

The Skill provides agent instructions. An explicitly reviewed setup installs repository-local commands and bindings; it preserves application metadata and tools.

Can I keep my test tools?

Yes. Application runners remain repository-owned. The protocol uses a host Python interpreter; current workspace operations need Git, Mise and Worktrunk. The guide names the prerequisites.

What does the evidence prove?

It records what passed for the observed source, and what was approved for delivery. It does not promise defect-free software or replace human judgment.
