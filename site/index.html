Read the setup guide
What gets installed?

The Skill contains Agent instructions and prepares its own isolated execution environment. Reviewed adoption adds project bindings while preserving application dependencies, entry files and existing tools.

Can I keep my test tools?

Yes. Application runners remain repository-owned. The protocol uses a host Python interpreter; current workspace operations need Git 2.7 or newer for Signetum's own commands, Mise and Worktrunk 0.74. Cleanup through Worktrunk needs Git 2.17. Worktrunk 0.75 or newer needs Git 2.43. The guide names the prerequisites.

Who coordinates the agents?

You and your coding-agent host decide which agents work on which tasks. Signetum supplies shared instructions, isolated workspaces and an explicit integration and delivery boundary; it is not a global agent or machine-resource scheduler.
