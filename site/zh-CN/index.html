阅读接入指南
安装之后，仓库会改变什么？

Skill 提供 Agent 指令。经明确审阅的接入方案才会添加仓库本地命令和绑定，保留应用的元数据与已有工具。

还可以使用原来的测试工具吗？

可以，应用测试方式仍由仓库自己定义。协议需要宿主 Python；当前工作区操作还需要 Git、Mise 和 Worktrunk。接入指南列出了这些前置条件。

谁来组织多个 Agent？

由你和编码 Agent 宿主分配任务、组织 Agent。Signetum 提供共同指令、隔离工作区，以及明确的集成与交付边界；它不是全局 Agent 或机器资源调度器。
