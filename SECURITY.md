# Security policy

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, private
repository data, or affected-user information. Use GitHub's private security
advisory reporting for this repository. Include the affected revision, public
boundary, reproduction conditions, expected safety property, observed behavior,
and any temporary mitigation.

## Scope

Reports may cover the packaged CLI, manifest and path validation, repository
inventory boundaries, lifecycle commands, validation evidence, batch delivery,
release artifacts, or GitHub workflows.

The Template does not provide a hosted service and does not update repositories
created from it. Those independent repositories own their deployed products,
credentials, and vulnerability response.
