# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers and maintainers using coding agents to change new or existing repositories.

## Product Purpose

Signetum is a standard Skill for reliable agentic development and delivery. It
connects approved requirements, retained decisions, behavioral checks and explicit
source-bound delivery through repository-owned commands.

## Operating Context

The Skill is the public entry. Setup is a reviewed adoption; daily work uses the
repository's local runtime and preserves its application tools. New and existing
projects share this path. Installation alone grants no mutation or delivery authority.

## Capabilities and Constraints

The website is static HTML/CSS with English and Chinese pages. Keep one clear
installation action and useful source/documentation links. Examples are illustrative;
there are no authorized testimonials, measured time savings or defect-free claims.

## Brand Commitments

Retain the Signetum name. The owner requested a replacement homepage, a compact
brand and a minimal maintained file set. The old mascot is not a binding identity.

## Evidence on Hand

README.md, QUICKSTART.md and the owner's redesign request supply the confirmed
product facts used by this delegated task; no separate audience interview occurred.
